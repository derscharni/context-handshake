## The idea in this repo: context-handshake

Every AI conversation, the human is the protocol. A context handshake changes that: structured, human-owned context that travels with you - to any agent, any platform, any model.

---

## Copy this into your LLM context

Layer 1: Security - sanitize every input. Log what you strip.
Layer 2: Authorization and context - declare who authorized what. Not inferred.
Layer 3: Temporal integrity - every memory decays. Track it.

The question to ask: "If this is wrong - who would notice, and when?"
